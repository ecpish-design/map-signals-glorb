# GLORB // Signal Mapper

Static GitHub Pages build. No server, database, analytics, or external libraries are required.

## Upload to GitHub
Upload `index.html` and the entire `assets/` folder. GitHub Pages can serve the site directly from the repository root.

## Student flow
- Enter name
- Choose `Map one feeling` or `Map the whole Signal System`
- One item per screen
- Responses: Yes / No / I don't know
- Optional student-written support and adult note
- Full mode maps Low, Steady, Rising, Overload, then Recovery / Return

## Outputs
- Adult Signal Map & Support Plan
- Escalation and recovery pathway
- Unknown / untried supports list
- Printable cut-out Support Menu cards
- Print / Save PDF
- Native Share or email fallback
- PNG support-summary image

## Privacy
Answers are kept in browser `sessionStorage` only. They are not transmitted by the site. Sharing happens only when the user chooses the Send action.
